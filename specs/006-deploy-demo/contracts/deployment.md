# 公网上线契约

## 配置与版本

生产部署使用 .env.example 中的全部现有变量名。仅 NEXT_PUBLIC_SUPABASE_URL 与 NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY 可公开，其余仅服务端。每个发布记录提交 SHA、部署 ID、环境、构建命令、URL 和验收时间。私有凭据及 .local/ 排除上传。

## 用户入口

/login 使用预置工号和密码，成功后按会话进入身份选择或助手。未选身份及未授权资源访问按现有行为拒绝。管理员中心和大盘按当前项目读取。

## 业务接口

/api/chat 沿用完整 UIMessage[]、sessionId 与 revision，工具只能准备草稿，用户确认动作才生成工单。失败显示中文提示并可恢复。草稿确认幂等，版本冲突保留已保存状态。

图片上传先校验会话、身份、数量和类型，再对唯一暂存路径授权直传。完成后服务端核实对象再关联。请求失败允许重试，退出或取消后的无引用对象按既有清理约定处理。实现可调整现有上传路由交互，但须覆盖所有现有调用者。

/api/work-orders/[number] 与照片读取入口逐次校验当前会话。私有照片继续经同源鉴权读取，验证大图传输及 cacheNonce 行为。聊天公开照片与工单私有照片保留各自存储约定。

## 验收证据

规范 SC-001 对应同一编号三角色记录，SC-002 对应真实文字、图文来源及失败提示，SC-003 对应两种视口和越权访问，SC-004 对应部署版本与演示步骤。HTTP 成功需结合实际业务结果判定。
