# 数据模型

## 复用实体

| 实体 | 关键字段与关系 | 校验 |
| --- | --- | --- |
| 当前身份 | Auth session_id、membership、project、role | 同一会话仅一个有效身份，每次受保护请求校验 |
| 工单 | 编号、项目、责任人、状态、version、描述、位置、专业、严重程度 | 受控 RPC 原子写入，expectedVersion 防覆盖 |
| 草稿 | 当前助手会话、状态、字段、照片选择、正式工单回执 | 确认前无正式编号，重复确认返回原工单 |
| 照片 | 对象路径、项目或会话归属、关联工单或草稿 | 最大 10 MiB，JPEG/PNG/WebP，正式工单最多九张 |
| 演示版本 | 提交 SHA、工作树说明、部署 ID、公网地址、环境、时间和验收结果 | 写入验收记录，不存入业务表，不包含密钥 |

## 状态与关联

草稿编辑中经用户确认转为已创建，并关联工单及唯一回执；取消、过期或退出失效沿用既有状态规则。正式工单待处理转为已解决，质检员重开后回到待处理，每步写处理记录。临时照片仅在确认事务后成为正式关联，草稿失效不能删除正式照片。

## 部署适配

计划复用现有存储对象与生命周期。直传授权绑定当前会话、路径、类型与大小，服务端验证对象后才允许快照或草稿关联。私有工单照片每次读取重新鉴权并禁用缓存。若需调整存储策略，在实施阶段添加最小迁移并验证普通账号权限。
