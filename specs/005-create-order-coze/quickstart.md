## 核心路径

| 场景 | 期望 |
| --- | --- |
| 单轮隔离 | 两次不同咨询均仅一个主题、不复用conversation_id、随机user_id、auto_save_history:false |
| 真实文字/图文知识 | 各一次，回答条文/数值/来源可对应真实Coze答案 |
| 知识失败/空/不足 | 明确未取得依据，不编造；配置恢复后重试 |
| 文字建单 | 质检员/管理员各一次，四项后即卡片，责任人在卡片选，点击确认才创建 |
| 缺项与意图 | 缺项追问；纯图意图不明先问；施工方不能建单；文字提交不代替点击 |
| 混合意图 | 知识成功后确认创建；失败后主动按事实也能创建，两者均经卡片 |
| 图片 | 聊天选保留/移除及相册新增，超9张/10MiB/非法类型拒绝；仅选图进入工单 |
| 取消/失败 | 取消零写入；上传、保存、提交失败保留内容；重复点击/响应丢失/刷新重试同草稿仅一单一记录 |
| 恢复与权限 | 同登录恢复已保存卡片；跨项目施工方/其他身份/旧草稿/退出后提交拒绝 |
| 生命周期 | 聊天淘汰或退出后已建工单图片保留；转派后原责任人旧详情/图失权 |
| 业务闭环 | 新单查询可见，创建→解决→重开→再解决，重新查询大盘与列表一致 |
| 响应式 | 390px与1440px卡片操作可达、无横向滚动，手机详情页/电脑抽屉可用 |
