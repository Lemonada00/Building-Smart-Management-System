## 实现修正

- Cache Components 开启时，认证 SDK 初始化的时间读取必须留在请求阶段；server 客户端使用 connection()，各页面将身份读取放在本页 Suspense 内，以覆盖同布局下导航。
- 开发工具改放右上角，避免遮挡窄屏导航底部的退出入口。
- 退出先撤销业务身份，再退出 Auth，使尚未过期的原访问令牌不能恢复业务身份。
- 本地迁移文件版本与云端迁移历史 `20261027132653` 对齐。

## 权限与安全检查

Supabase Advisors 已检查。私有身份表开启 RLS 且无普通用户策略是有意的默认拒绝设计，客户端无表权限，仅经核验 uid、session_id 和成员关系的私有函数访问；公开 RPC 使用 invoker 包装，非公开 schema 未暴露。云项目现有“泄露密码保护未启用”提示留作上线配置记录，本阶段未修改该项目级配置；演示账号由随机密码生成。参考：[Supabase 密码保护说明](https://supabase.com/docs/guides/auth/password-security#password-strength-and-leaked-password-protection)。
